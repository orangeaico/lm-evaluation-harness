# Repo-Eval Tasks

This directory contains LLM evaluation tasks for repository-level code understanding, focusing on component location and code identification within Python codebases.

## Tasks

### DefinedIn (`repo_eval_defined_in`)

**Description**: Given a component name and type (class/function), identify where it's defined in the codebase.

**Input Format**:
- Component name (e.g., "DataArray")
- Component type ("class" or "function")

**Output Format**: JSON with:
```json
{
  "absolute_path": "path/to/file.py",
  "filename": "file.py",
  "class": "ClassName or null"
}
```

**Metrics**:
- `defined_in_exact_match`: All fields must match exactly
- `defined_in_partial_match`: Only absolute_path must match

### BelongsTo (`repo_eval_belongs_to`)

**Description**: Given a code chunk, identify which file and component it belongs to.

**Input Format**: Code snippet (30% of original source)

**Output Format**: JSON with:
```json
{
  "absolute_path": "path/to/file.py",
  "component_path": "ClassName.method_name or function_name"
}
```

**Metrics**:
- `belongs_to_exact_match`: Both fields must match exactly
- `belongs_to_partial_match`: Only absolute_path must match

## Usage

### Individual Tasks
```bash
# Run DefinedIn task only
lm_eval --model hf --model_args pretrained=<model_name> --tasks repo_eval_defined_in

# Run BelongsTo task only
lm_eval --model hf --model_args pretrained=<model_name> --tasks repo_eval_belongs_to
```

### All Tasks
```bash
# Run all repo-eval tasks
lm_eval --model hf --model_args pretrained=<model_name> --tasks repo_eval
```

## Data Source

Tasks load data from locally generated JSONL files:
- `data/tasks/*/*/DefinedIn.jsonl`
- `data/tasks/*/*/BelongsTo.jsonl`

These files are generated by the repo-eval task generation pipeline from Python repositories and contain self-sufficient prompts ready for LLM evaluation.

## Task Properties

- **Zero-shot evaluation**: No few-shot examples (num_fewshot: 0)
- **Generative format**: Models generate JSON responses
- **JSON validation**: Responses are parsed and validated as JSON
- **Repository scope**: Focuses on top-level classes and functions only
- **Difficulty levels**: Tasks are categorized as easy/medium/hard

## Dataset Coverage

Current tasks are generated from:
- **xarray**: Scientific computing library
- **Commits**: Multiple commits from SWE-bench_Verified dataset
- **Components**: Classes, functions, and async functions (methods excluded)
